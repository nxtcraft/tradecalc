What is a pip?

  • For EUR/USD: 1 pip = 0.0001 (4th decimal place)
  • For USD/JPY: 1 pip = 0.01 (2nd decimal place)
  • Standard lot (100K): 1 pip = $10 for USD-quoted pairs
  • Mini lot (10K): 1 pip = $1 for USD-quoted pairs
